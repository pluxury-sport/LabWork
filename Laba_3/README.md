Лабораторная работа 3 (Задача 5)

Описание
Программа вычисляет геометрический центр (среднее арифметическое по координатам X, Y и Z) для множества точек в 3D-пространстве. Реализованы две версии параллельных вычислений с использованием технологии OpenMP:
1. Версия 1 (reduction): Распараллеливание цикла с использованием редукции.
2. Версия 2 (sections): Функциональная декомпозиция (разделение задач по осям координат).

Особенность: Если файл с исходными данными (`crd_big.txt`) отсутствует, программа автоматически сгенерирует его, создав 100 000 случайных точек. Это позволяет запускать программу на любом компьютере без необходимости вручную подготавливать файл.

Сборка (g++)

g++ Laba3_zadacha5.cpp -o Laba3_zadacha5 -fopenmp

Запуск
Laba3_zadacha5.exe

Версия 1: parallel for + reduction
Использует директиву #pragma omp parallel for reduction(+:sumi_x, sumi_y, sumi_z). Итерации одного цикла делятся между потоками. Каждый поток считает свою локальную сумму, после чего OpenMP безопасно складывает их в глобальные переменные без использования критических секций.

Версия 2: parallel sections
Использует директиву #pragma omp parallel sections. Работа делится не по итерациям, а по задачам. Создаются три независимые секции: одна ищет сумму по X, вторая по Y, третья по Z. Этот метод показывает высокую эффективность при функциональной декомпозиции.

В конце работы программа выводит вычисленные координаты центра и время выполнения для обеих версий, что позволяет наглядно сравнить их производительность.
