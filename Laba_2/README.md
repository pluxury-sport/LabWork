Лабораторная работа 2 (Задача 4 — Перемножение матриц)

Сборка (g++)

g++ Code.cpp -o Code4 -fopenmp

Запуск

Code4.exe

Описание работы программы:
Программа не требует ввода данных. При запуске она автоматически:
1. Создает и инициализирует две квадратные матрицы `A` и `B` размером 700x700 (матрица `A` заполняется единицами, `B` — двойками).
2. Выполняет классическое последовательное перемножение матриц и замеряет затраченное время с помощью `omp_get_wtime()`.
3. Выполняет параллельное перемножение матриц в цикле для 2, 4 и 8 потоков. Перед каждым запуском результирующая матрица `C` очищается.
4. Выводит в консоль время выполнения как для последовательного алгоритма, так и для каждого варианта с потоками, что позволяет наглядно оценить прирост производительности (ускорение) от использования OpenMP.

вывод в консоль:
Последовательное время: 5.12345 сек.
Потоков: 2, время: 2.65432 сек.
Потоков: 4, время: 1.41234 сек.
Потоков: 8, время: 0.98765 сек.
