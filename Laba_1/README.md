Лабораторная работа 1 (Задачи 1–3)

Сборка (g++)

g++ Code1.cpp -o Code1 -fopenmp
g++ Code2.cpp -o Code2 -fopenmp
g++ Code3.cpp -o Code3 -fopenmp

Запуск

Задача 1 — идентификаторы потоков

Code1.exe

Программа запрашивает число потоков. Ввести, например: `8`. Программа выводит для каждого потока его идентификатор, общее число потоков и строку "Hello World!".

Задача 2 — среднее значение по массиву

Code2.exe

Программа запрашивает:

1. Число потоков (например, `8`)
2. Тип schedule: `static`, `dynamic`, `guided` или `runtime`

Вычисляет среднее по массиву 16000 элементов, выводит время и первые 10 элементов результата.

Задача 3 — обратный порядок идентификаторов

Code3.exe

Программа запрашивает число потоков (например, `8`).

Выводит идентификаторы потоков в обратном порядке пятью способами:
1. Использование директивы `ordered`
2. Через массив идентификаторов
3. Барьеры и проверка ID
4. Разделяемый счетчик `maxid`
5. Цикл с барьером
