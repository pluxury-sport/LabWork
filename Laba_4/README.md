Лабораторная работа 4 (Задача 6)

Описание
Программа вычисляет значение по формуле (Σx + Σy + Σz) / 3N для множества точек в 3D-пространстве, где N — количество точек.
В задаче требуется использовать функциональную декомпозицию (разделение задач) и критические секции для безопасного вычисления глобальной суммы.

Особенность: Если файл с исходными данными (`crd_big.txt`) отсутствует, программа автоматически сгенерирует его. В файл запишутся 100 000 случайных точек с координатами от -1000.0 до 1000.0 (включая отрицательные значения). Это позволяет запускать программу на любом компьютере без необходимости вручную подготавливать файл.

Сборка (g++)
g++ Laba4_zadacha6.cpp -o Laba4_zadacha6 -fopenmp

При запуске программа запрашивает количество потоков для вычислений (например, 8).

1. Генерация данных
Если файла crd_big.txt нет, программа создает его, заполняя 100 000 строк случайными дробными числами от -1000 до 1000. Генерация использует rand() и srand(time(0)), чтобы числа были разными при каждом запуске.

2. Функциональная декомпозиция (sections)
Вместо распараллеливания одного цикла, программа использует директиву #pragma omp parallel sections. Работа делится на три независимые задачи (секции):

Секция 1: Суммирует все координаты по оси X.

Секция 2: Суммирует все координаты по оси Y.

Секция 3: Суммирует все координаты по оси Z.

3. Критические секции (critical)
Все три секции одновременно прибавляют числа к одной общей переменной global_sum. Чтобы потоки не мешали друг другу и не теряли данные (состояние гонки), каждая операция сложения обернута в критическую секцию #pragma omp critical. Это гарантирует, что в каждый момент времени переменную изменяет только один поток.

4. Итоговый результат
После завершения всех потоков вычисляется итоговое значение по формуле: global_sum / (3.0 * N). Программа выводит результат и время выполнения.
